## ¿Cómo abrir esto en Obsidian?

1. Abrí Obsidian → **Open folder as vault**.
2. Elegí la carpeta raíz del repo: `Bookwise-API/` (o `docs/` si querés solo la documentación).
3. Los archivos Markdown aparecen en el explorador; el índice navegable es `docs/index.md`.

> Obsidian respeta el Markdown estándar (tablas, code blocks, callouts `> [!info]`). Los enlaces wiki solo resuelven dentro del vault abierto.
